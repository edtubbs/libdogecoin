## Root Cause Analysis:
#
# The on-chain transactions were produced by edtubbs/dogecoin branch
# copilot/add-pqc-implementation. That implementation's GUI (sendcoinsdialog.cpp)
# signs a CUSTOM domain-separated digest instead of sighash32(TX_BASE):
#
#   message = SHA256("DGC-PQC-SIG-V1|" + algorithm + "|" + pubkey_hex + "|"
#                    + address + "|" + amount + "|" + subtractFee + ";")
#
# This does NOT match the BIP spec which requires:
#   message32 = dogecoin_tx_sighash32(TX_BASE, scriptPubKey, input_index, hash_type)
#
# The libdogecoin SPV verification correctly reconstructs TX_BASE per the spec.
# The fix must be applied in the dogecoin node's PQC implementation to sign
# sighash32(TX_BASE) instead of the custom digest.
